# Music for the mig demo video

`music.opus` is the music the mig demo video's encoder lays under the video.

- Title: Swan ride
- Author: TRG Banks
- Album: Pantomime Town (2018)
- Source: https://freemusicarchive.org/music/TRG_Banks/Pantomime_Town/Swan_ride
- Copy downloaded from Wikimedia Commons:
  https://commons.wikimedia.org/wiki/File:TRG_Banks_-_01_-_Swan_ride.ogg (file:
  https://upload.wikimedia.org/wikipedia/commons/a/ad/TRG_Banks_-_01_-_Swan_ride.ogg)
- Licence: CC0 1.0 Universal, a public domain dedication
  (https://creativecommons.org/publicdomain/zero/1.0/). Both pages above state
  it. It allows commercial use with no attribution; this file names the source
  anyway.

The file here is 90 seconds of the track starting at 1:19, where it is already
steady, re-encoded to Opus at 96 kbit/s, stereo, with all metadata removed and
no other change. The video's encoder trims it to the video's length, sets its
level, and fades it in and out.
